# MongoDB, AJAX/PHP and AngularJS (COMP 4621)

Assignment 2 for COMP 4621 (Web Development) at Thompson Rivers University, in three parts.

| Folder | What it is |
|---|---|
| `Part1_MongoDB/` | A product catalog in MongoDB with a flexible schema and a `$jsonSchema` validator |
| `Part2_AJAX/` | A person lookup page that calls a PHP endpoint with AJAX and shows the JSON result, with error handling |
| `Part3_AngularJS/` | A phone directory in AngularJS with search, sorting, add/remove and form validation |

## Run it
**Part 1:** `mongosh Part1_MongoDB/product_catalog.js` (needs MongoDB running).

**Part 2:** from `Part2_AJAX/`, run `php -S localhost:8000`, then open http://localhost:8000.

**Part 3:** open `Part3_AngularJS/index.html` in a browser. AngularJS is included locally.
